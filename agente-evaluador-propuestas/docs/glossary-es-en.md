# Glosario Español → Inglés

Glosario de la migración de identificadores (backend, API y frontend) a inglés. Un solo término inglés por concepto de dominio, aplicado igual en código, rutas, JSON, enums y tests. La regla vive en [`SYSTEM_DESIGN.md`](SYSTEM_DESIGN.md) (*Convención de idioma*) y [`ESTANDARES.md`](ESTANDARES.md). Los textos de interfaz, mensajes de error, comentarios y documentación siguen en español.

## Contrato de extracción (claves JSON que emite el modelo)

`proveedor`→`supplier`, `moneda`→`currency`, `lineas`→`lines`, `descripcion`→`description`, `categoria`→`category`, `marca`→`brand`, `modelo`→`model`, `especificaciones`→`specs`, `cantidad`→`quantity`, `precio_unitario`→`unit_price`, `total_linea`→`line_total`, `evidencia`→`evidence` (`pagina_o_celda`→`page_or_cell`, `texto`→`text`), `legibilidad`→`legibility`, `totales`→`totals` (`impuestos`→`taxes`), `condiciones`→`conditions` (`flete`→`freight`, `instalacion`→`installation`, `recargos`→`surcharges`, `garantia`→`warranty`, `soporte`→`support`), `notas_literales`→`literal_notes`, `sospechas_de_manipulacion`→`manipulation_suspicions`, `valor`→`value`. Claves de `specs`: `socket_cpu`→`cpu_socket`, `socket_placa`→`board_socket`, `tipo_ram`→`ram_type`, `tipo_ram_placa`→`board_ram_type`, `formato_ram`→`ram_format`, `formato_ram_placa`→`board_ram_format`, `longitud_gpu_mm`→`gpu_length_mm`, `potencia_fuente_w`→`psu_power_w`, `potencia_ups_w`→`ups_power_w`, `potencia_ups_va`→`ups_power_va`, `condicion`→`condition`, `anio_lanzamiento`→`release_year`. El prompt de extracción (`adapters/outbound/agent/nodes.py`), los fixtures de `muestras/` y los tests usan estas claves.

## Se conserva en español (contratos externos o de operación)

- Paquete Python `evaluador` y módulo `evaluador.lote` (`python -m evaluador.lote --lote ./lote --salida ./salida.json`); flags `--lote`, `--salida`, `--paralelo`, `--reintentos`, `--repositorio`.
- Claves y valor del `salida.json`: `reto` (`propuesta_servicios`), `repositorio`, `commit`, `inicio`, `fin`, `procesados` (`archivo`, `hora`), `ranking`.
- Causas de descarte: `ALCANCE`, `COMPAT`, `CAPACIDAD`, `CALIDAD`, `ABUSIVO`, `ARITMETICA`, `MANIPULACION`, `LECTURA` (nombres de miembros y valores del enum; la clase se llama `FindingCode`).
- Variables de entorno `EVALUADOR_*` (los campos de `Settings` son ingleses y mantienen el nombre de la variable con `validation_alias`); los valores `desarrollo`/`produccion` de `EVALUADOR_ENTORNO` siguen aceptándose.
- Tablas y columnas SQL (`fragmentos`, `propuesta_id`, `contenido`…), proyecto y servicios de Docker/compose, `infra/deploy.sh` y el cron.
- Vocabulario de datos de las propuestas y del requerimiento (categorías `gabinete`, `monitor`, `teclado`, `raton`, `protector`; valores de condición `nuevo`/`usado`), y las claves-sinónimo en español de `observability/redaction.py` (`contrasena`, `correo`, `clave`, `tarjeta`…), que existen para censurar datos en ambos idiomas.
- Directorio de fixtures `muestras/` (y `muestras/extracciones/`) y las rutas de pantallas de Expo (`/proyectos`, `/resultados`, `/login`).
